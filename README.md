# 📘 Sistema de Registro de Notas - IE Virgen de Fátima

## 📋 Descripción
Sistema web completo para la gestión académica de la Institución Educativa N.º 70541 **“Virgen de Fátima”**.  
Permite a los docentes gestionar cursos, sesiones de aprendizaje, registrar notas y generar reportes detallados de manera rápida y segura.

---

## ✨ Características Principales

### 🎯 Funcionalidades
- 🔐 **Autenticación segura para docentes**
- 📊 **Dashboard** con métricas y actividades recientes
- 📚 **Gestión de cursos** y sesiones de aprendizaje
- 📝 **Registro de notas** por sesión y examen
- ✔️ **Listas de cotejo** con criterios de evaluación
- 📤 **Reportes exportables a Excel**
- 👨‍🎓 **Gestión de estudiantes** con filtros avanzados
- ⚙️ **Configuración de perfil** para docentes

---

## 📦 Módulos del Sistema

- **Dashboard:** Vista general del sistema con métricas
- **Cursos:** Gestión de cursos, sesiones y exámenes
- **Notas:** Registro y administración de calificaciones
- **Reportes:** Generación de reportes individuales y completos
- **Estudiantes:** Listado y detalles de alumnos
- **Configuración:** Opciones del perfil del usuario docente
